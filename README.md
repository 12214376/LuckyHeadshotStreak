# 抢枪爆头好运连连 (Lucky Headshot Streak)

- 中文名：抢枪爆头好运连连
- 英文名：Lucky Headshot Streak
- 作者 GitHub：[@12214376](https://github.com/12214376)
- Mod ID：`creature_radar`（兼容原配置键位与资源路径）
- 当前版本：`1.0.0`
- 打开配置键：`P`

## 安装

1. 安装对应游戏环境后，将 [dist/LuckyHeadshotStreak-1.0.0.jar](dist/LuckyHeadshotStreak-1.0.0.jar) 放入 `mods`
2. 启动游戏，按 `P` 打开配置界面

## 仓库结构

- `dist/` 预构建 jar
- `src/main/java` 源码
- `src/main/resources` 资源与配置
- `reference/decompiled` 参考代码
